# 🚗 Velocímetro - Monitor de Velocidade em Tempo Real

[![Android](https://img.shields.io/badge/Platform-Android-3DDC84.svg?style=flat&logo=android&logoColor=white)](https://developer.android.com/)
[![Kotlin](https://img.shields.io/badge/Language-Kotlin-7F52FF.svg?style=flat&logo=kotlin&logoColor=white)](https://kotlinlang.org/)

O **Velocímetro** é um aplicativo Android desenvolvido para medir e exibir a velocidade de deslocamento em tempo real utilizando o GPS do dispositivo.

---

## 📌 Sobre o Projeto

Este aplicativo foi idealizado para auxiliar no monitoramento da velocidade do veículo em situações de emergência ou conveniência — como quando o velocímetro original do painel do carro apresenta falhas ou defeitos.

Com uma leitura precisa via satélite, ele funciona como um painel auxiliar de segurança para o motorista.

---

## ✨ Funcionalidades

- 🛰️ **Medição via GPS:** Leitura contínua da velocidade em tempo real.
- 🚘 **Painel Auxiliar:** Suporte ao motorista em caso de problemas no painel do veículo.
- 📱 **Interface Limpa:** Foco na leitura rápida e fácil sem distrações na direção.

---

## 🛠️ Tecnologias Utilizadas

- **Plataforma:** Android
- **Linguagem:** Kotlin
- **Serviços:** GPS / Location Services
- **IDE:** Android Studio
